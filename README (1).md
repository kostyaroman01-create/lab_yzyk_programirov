### Задание 4 **(2)**

*Почему присваивание* ```(++x)=y``` *является синтаксически правильным, а*
```(x++)=y``` - *нет? Запишите текст сообщения об ошибке, переведите и объясните его.*

* выражение должно быть допустимым для изменения левосторонним значением
* '=': левый операнд должен быть l-значением
* (++x)=y: у него есть адрес, его можно изменить → присваивание разрешено. Сначала x станет x+1, затем в него запишется y.
* (x++)=y: x++ у него нет адреса, изменить его нельзя → присваивание запрещено. Компилятор выдаёт ошибку «левый операнд должен быть l-значением».
