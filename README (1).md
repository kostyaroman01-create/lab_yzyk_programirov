### Задание 4 **(2)**
*Рассмотрим следующий пример в IDLE Python*
```
>>> x = 99.99
>>> int(x/10+0.001)
9
```
*Результат должен был быть равен 10, однако оказался другим. Почему так произошло?
Как исправить программу, чтобы она корректно переводила вещественные числа в целые?*

* в компьютере x= 99.99 представляется чуть меньше 99.98999999999999488
* когда мы делим x/10 то x=9.998999999999999 тоже чуть меньше 9,999...
* и когда мы прибовляем x+0,001=9.998999999999999 +0,001=9.999999999999998, а int просто отбрасывает дробную часть

* можно просто добавить round()
```
x = 99.99
d=round(x/10+0.001)
print(d)
10
```

### Задание 7 **(2)**

*Допишите что-либо вместо многоточия программе на С++, чтобы программа при запуске выдавала ответ* **yes**.
```
double s = NaN;
if (s != s)
  std::cout << "yes";
```
NaN расшифровывается как Not a Number — «не число».
Это специальная битовая комбинация в формате double, которая означает:

«Результат операции не определён / не является числом».

Например:
0/0 — не определено,
корень(-1)  — не существует среди вещественных чисел,
log(−1) — не существует,
∞−∞ — не определено,
0⋅∞ — не определено.

Во всех этих случаях процессор не может вернуть «нормальное» число и вместо него кладёт в результат NaN.
