### Задание 4 **(2)**

*Почему присваивание* ```(++x)=y``` *является синтаксически правильным, а*
```(x++)=y``` - *нет? Запишите текст сообщения об ошибке, переведите и объясните его.*


The expression must be permissible for modification by a left‑hand value -- выражение должно быть допустимым для изменения левосторонним значением

* выражение должно быть допустимым для изменения левосторонним значением
* '=': левый операнд должен быть l-значением
* (++x)=y: ++x увеличевается а потом присваевает себя поэтому невызывает ошибку
* (x++)=y: x++ он создает копию которая приравнивает себя увеличевается а потом возвращает старое значение
