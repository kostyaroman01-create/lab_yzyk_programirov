### Задание 2 **(2)**
*Проверьте работу следующей программы на С++*
```
#include <iostream>
int main() {
   {
      int x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   {
      double x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   return 0;
}
```
*Нужны ли в этой программе вложенные фигурные скобки? Дайте подробный ответ с объяснением причин.*
* Да, скобки здесь нужны, и по сути обязательны. Фигурные скобки создают вложенную область видимости, потому что в C++ в одной области видимости имя может быть объявлено только один раз, без скобок x и y были в одной области main и компилятор выдал ошибку повторного обьявления, а не типов. Скобки ограничивают видимость, поэтому ошибки нет, еще после выхода из 1 блока переменные формально удаляются, до 2 блока, что экономит память, и предотвращает повторное использованием старых имен, если мы во 2 блоке назначим другие переменные(c, d), то скобки будут необязательны, но их использовать для удалении уже использованых переменных и области видимости.

### Задание 7 **(2)**

*Рассмотрим программу на языке* **Python**.
```
a = 'Hello world'
print(a, id(a))
b = a
print(b, id(b))
a += ' and goodbye'
print(a, id(a))
print(b, id(b))
```
*Объясните ее работу. В какой момент создавались строки? 
Что означает значение, возвращенное функцией* **id**?
что такое переменная в питоне ,смысл вот этого
* id(x) - позволяет узнать местоположение объекта. Но
использовать его можно только для сравнения.
```
a = 'Hello world' к а присваевается строка
print(a, id(a)) а остается строкой и выводется его уникальный номер
b = a b ссылается на а но id его другой
print(b, id(b)) b остается строкой и выводется его номер 
a += ' and goodbye' создается новая строка и перепривязывается в а, id меняется
print(a, id(a)) а остается строкой и выводется его уникальный номер измененный
print(b, id(b)) b остается строкой и выводется его уникальный номер
```
* переменная это запись в словаре
* 'Hello world' - a = 'Hello world', ' and goodbye'- 'Hello world and goodbye' новый обьект, b=a строка не создалась.
* a и b сначала ссылаются на один объект (одинаковый id), а после += на разные обьекты (разные id), потому что += для неизменяемых строк создаёт новую строку и перепривязывает только имя a.
