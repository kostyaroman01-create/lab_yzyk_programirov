## Задание 1
Напишите пример программы на С++ с использованием
целочисленных литералов в разных форматах записи, разной длины,
знаковых и беззнаковых. Пример должен охватывать большинство
способов записи целочисленных литералов.
```
#include <iostream>

int main() {
    // 1. СИСТЕМЫ СЧИСЛЕНИЯ (Форматы записи)
    // Все четыре переменные ниже инициализируются числом 42
    int decimal     = 42;        // Десятичный формат (по умолчанию)
    int octal       = 052;       // Восьмеричный формат (начинается с нуля '0')
    int hex         = 0x2A;      // Шестнадцатеричный формат (начинается с '0x' или '0X')
    int binary      = 0b101010;  // Двоичный формат (начинается с '0b' или '0B', начиная с C++14)

    std::cout << "--- Системы счисления (все равны 42) ---\n";
    std::cout << "Dec: " << decimal << ", Oct: " << octal 
              << ", Hex: " << hex << ", Bin: " << binary << "\n\n";


    // 2. СУФФИКСЫ МОДИФИКАЦИИ ТИПА (Знаковость и Длина)
    // Беззнаковые (Unsigned) — суффикс 'U' или 'u'
    unsigned int u_val = 150U;

    // Длинные целые (Long) — суффикс 'L' или 'l' (лучше заглавная L, чтобы не путать с 1)
    long l_val = 3000000000L;

    // Очень длинные целые (Long Long) — суффикс 'LL' или 'll' (начиная с C++11)
    long long ll_val = 9000000000000000000LL;

    // Комбинации суффиксов (Порядок U и L/LL не имеет значения)
    unsigned long ul_val      = 4000000000UL;       // Unsigned Long
    unsigned long long ull_val = 0xFFFFFFFFFFFFFFFFULL; // Unsigned Long Long (Hex-формат)

    std::cout << "--- Суффиксы знака и длины ---\n";
    std::cout << "unsigned int: " << u_val << "\n";
    std::cout << "long:         " << l_val << "\n";
    std::cout << "long long:    " << ll_val << "\n";
    std::cout << "unsigned LL:  " << ull_val << "\n\n";


    // 3. РАЗДЕЛИТЕЛИ РАЗРЯДОВ (Начиная с C++14)
    // Одинарная кавычка (') может ставиться между цифрами для удобства чтения
    long long separated_dec = 1_000_000_000_000LL; // Читается как 1 триллион
    int separated_hex       = 0xDE_AD_BE_EF;        // Разделение по байтам
    int separated_bin       = 0b0010'1010'1101;     // Разделение по полубайтам (нибблам)

    std::cout << "--- Разделители разрядов ---\n";
    std::cout << "Dec separated: " << separated_dec << "\n";
    std::cout << "Hex separated: " << std::hex << separated_hex << std::dec << "\n";
    std::cout << "Bin separated: " << separated_bin << "\n";

    return 0;
}
```
Короткая шпаргалка по целочисленным литералам:
• Префиксы (Определяют систему счисления):
	• Нет префикса — десятичная (например, 10)
	• 0 — восьмеричная (например, 012 равно 10 в десятичной)
	• 0x / 0X — шестнадцатеричная (например, 0xA)
	• 0b / 0B — двоичная (например, 0b1010)
• Суффиксы (Определяют тип данных):
	• U / u — беззнаковый (unsigned)
	• L / l — длинный (long)
	• LL / ll — очень длинный (long long)
	• Совет: Всегда пишите заглавную L (например, 10L, а не 10l), так как строчную букву l легко перепутать с цифрой 1.

• Правила, по которым компилятор автоматически выбирает тип числа, если вы вообще не указали суффиксы
• Как работают литералы для пользовательских типов данных (User-defined literals), появившиеся в современных стандартах C++

В ходе объяснения следует использовать таблицу кодов символов.
• Тип char — это целочисленный тип данных, который обычно занимает 1 байт (8 бит) [1] и хранит числовой код символа. В большинстве современных систем используется таблица ASCII.
• В зависимости от настроек компилятора и платформы, тип char по умолчанию может быть либо знаковым (signed), либо беззнаковым (unsigned). Чаще всего он является знаковым (signed char), и его диапазон значений составляет от -128 до 127.
* у нас а = 'a'(97)
• К коду символа прибавляется 10: 97 + 10 = 107.
• Число 107 находится в диапазоне типа char (меньше 127). код 107 принадлежит символу 'k'.
• На экран выведется буква k.

## Задание 3 (2) 
Перепишите программу из задания выше на Python, используя
функции chr и ord. Почему ее вывод отличается от вывда программы
на С++.
```
# Инициализируем переменную символом 'a'
a = 'a'

# Шаг 1: Прибавляем 10 к коду символа и превращаем обратно в символ
a = chr(ord(a) + 10)
print(a, end="")

# Шаг 2: Прибавляем 250 к коду текущего символа и превращаем в символ
a = chr(ord(a) + 250)
print(a, end="")
print()  # Перенос строки
```
вывод kś
Вывод отличается из-за принципиальной разницы в том, как устроены типы данных и как кодируются символы в этих языках.
1. Отсутствие переполнения памяти
• В C++ тип char жестко ограничен размером в 1 байт (8 бит). Когда в C++ мы попытались записать в него число 357, оно физически не поместилось в память. Произошло переполнение разрядной сетки, число «прокрутилось» по кругу (357 % 256) и превратилось в 101 (код символа 'e').
• В Python строки состоят из символов Юникода, а целые числа (которые возвращает функция ord()) имеют произвольную точность и не ограничены одним байтом. Операция 107 + 250 честно выдает результат 357. Никакого переполнения или отсечения разрядов не происходит.
2. Разные таблицы кодировок (ASCII/Extended ASCII vs Unicode)
• В C++ стандартный вывод ориентируется на однобайтовые кодировки. Число 101 после переполнения дало нам символ 'e' из базовой таблицы ASCII.
• В Python функция chr() работает с кодировкой Unicode (Юникод), которая содержит более 140 000 символов. Число 357 в таблице Unicode закреплено за латинской буквой ś (буква «s» с акутом/ударением, используемая, например, в польском языке).
Итог
C++ «сбросил» значение обратно в рамки первого байта (до 255) из-за ограничений типа данных, поэтому получился символ из начала таблицы ASCII ('e'). Python же сохранил точное математическое значение 357 и вывел соответствующий ему символ из расширенной таблицы Юникода ('ś').
