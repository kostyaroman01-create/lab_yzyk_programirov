# задание 1
Маршрутка
Водители маршруток согласны делать рейс только если все места заняты. Вместимость маршрутки 15 человек. На остановку пришло n человек. Определите, сколько людей сможет уехать на маршрутках, и скольким придется добираться другими способами.

Формат входных данных
Одно натуральное число — количество человек на остановке.

Формат результата
Через пробел два целых числа — количество людей, уехавших на маршрутках, и количество людей, оставшихся на остановке.

Примеры
Входные данные
72
Результат работы
60 12


# задание 2
Сумма половин
Дано натуральное число, состоящее из четного количества цифр. Десятичная запись числа разрезается посередине. Найдите сумму первой и второй половины числа. Например для 206198 ответом будет 404, так как 206+198=404.

Формат входных данных
Одно целое положительное число, состоящее из четного количества цифр

Формат результата
Одно число — ответ к задаче.

Примеры
Входные данные
206198
Результат работы
404

# задание 3
Жажда
У трех путешественников в пустыне осталось n литров воды. Они решили поделить воду поровну. Сколько воды получит каждый. Выведите ответ с точностью до миллилитра

Формат входных данных
Одно натуральное число n.

Формат результата
Одно вещественное число c заданной точностью

Примеры
Входные данные
2
Результат работы
0.667
Входные данные
1
Результат работы
0.333

# задание 4
Рубли и копейки
Цена товара указана в рублях в виде одного вещественного числа не более чем с двумя знаками после точки. Требуется вывести цену товара в рублях и копейках. Формат вывода смотрите в примерах

Формат входных данных
Одно вещественное положительное число не более чем с двумя знаками после точки Число не превосходит 1000.

Формат результата
В первой строке вывести буквы номера, а во второй строке — цифры

Примеры
Входные данные
10.34
Результат работы
10 rub 34 kop
Входные данные
15.7
Результат работы
15 rub 70 kop
Входные данные
100
Результат работы
100 rub 0 kop

# задание 5
Отчет
Организации требуется распечатать отчет на принтере. Отчет требуется напечатать в n экземплярах. Отчет состоит из m листов. Для печати отчета требуется закупить бумагу. Бумага продается пачками по 200 листов. Одна пачка бумаги стоит c рублей. При этом в конторе осталась одна начатая пачка бумаги, в которой осталось k листов. Сколько денег придется потратить для закупки бумаги для печати отчета.

Формат входных данных
Через пробел записаны 4 натуральных числа: n, m, c, k. Все числа не превосходят 1000.

Формат результата
Одно число — ответ к задаче.

Примеры
Входные данные
3 220 195 60
Результат работы
585
Входные данные
1 450 200 20
Результат работы
600

# задание 6
Подарки
Деду Морозу требуется положить в каждый из n подарков по m конфет. Конфеты лежат в коробках, в каждой коробке ровно k конфет. Какое количество коробок придется раскрыть, чтобы собрать все подарки?

Формат входных данных
Через пробел записаны три натуральных числа n, m, k. Все числа не превышают 1000.

Формат результата
Вывести одно число — ответ к задаче.

Примеры
Входные данные
50 10 100
Результат работы
5
Входные данные
9 7 50
Результат работы
2
