# задание 5
Отчет
Организации требуется распечатать отчет на принтере. Отчет требуется напечатать в n экземплярах. Отчет состоит из m листов. Для печати отчета требуется закупить бумагу. Бумага продается пачками по 200 листов. Одна пачка бумаги стоит c рублей. При этом в конторе осталась одна начатая пачка бумаги, в которой осталось k листов. Сколько денег придется потратить для закупки бумаги для печати отчета.

Формат входных данных
Через пробел записаны 4 натуральных числа: n, m, c, k. Все числа не превосходят 1000.

Формат результата
Одно число — ответ к задаче.

Примеры
Входные данные
3 220 195 60
Результат работы
585
Входные данные
1 450 200 20
Результат работы
600
```
import math

n, m, c, k = map(int, input().split())
l=(m*n)-k
if(l<=0):
    d=0
else:
    d=c*(math.ceil(l/200))
print(int(d))
```

Однажды Алиса написала на полоске бумаги строчку, состоящую из открывающих и закрывающих круглых скобок, и положила эту полоску на стол, перпендикулярно зеркалу, которое там стояло. К ее удивлению в зеркале она тоже увидела последовательность скобок, но немного другую.

Ваша задача — по исходной последовательности скобок найти ее отражение.

Формат входных данных
Одна строка, состоящая только из круглых скобок. Длина строки не превосходит 50 символов.

Формат результата
Одна строка — отражение исходной строки.

Примеры
Входные данные
(()(())
Результат работы
(())())
```
s = input().strip()

def mirror(c):
    return ')' if c == '(' else '('

result = ''.join(mirror(c) for c in reversed(s))
print(result)
```

# задание 12
Минимальные делители
В одной строке через пробел записано несколько целых чисел. Для каждого из чисел программа должна найти и вывести его минимальный делитель больший единицы. Все ответы выводятся в одной строке через пробел.

Формат входных данных
Несколько чисел, записанных через пробел в одной строке. Общее количество чисел и сами числа не превосходят 1000.

Формат результата
Через пробел в одной строке минимальные делители.

Примеры
Входные данные
20 121 41 91
Результат работы
2 11 41 7
```
def min_divisor(n):
    d = 2
    while d * d <= n:
        if n % d == 0:
            return d
        d += 1
    return n   # n простое

nums = list(map(int, input().split()))
print(' '.join(str(min_divisor(n)) for n in nums))
```

# задание 14
Игра в пробке
Маша и Даша идут в школу мимо длинной автомобильной пробки. Чтобы потренироваться в устном счете, они играют в такую игру. Берется номер автомобиля, стоящего в пробке. Если номер делится на 3 без остатка, то два очка получает Маша, иначе одно очко получает Даша.

По номерам всех автомобилей, стоящих в пробке определите счет в конце игры

Формат входных данных
В первой строке записано натуральное число n, n≤1000. В следующих n строках по одному в строке записаны n натуральных чисел — номера автомобилей.

Формат результата
Вывести счет игры: количество очков у Маши и количество очков у Даши через двоеточие.

Примеры
Входные данные
4
2301
1993
2570
3311
Результат работы
2:3
```
n = int(input())
masha = 0
dasha = 0

for _ in range(n):
    num = int(input())
    if num % 3 == 0:
        masha += 2
    else:
        dasha += 1

print(f"{masha}:{dasha}")
```
# задание 15
Прибыль
Компании предложили выполнить некоторое количество работ. Для каждой работы известна ее стоимость, а специалисты компании определили затраты на ее выполнение. Ваша задача — определить какую максимальную прибыль может получить компания в результате выполнения некоторых из предложенных работ

Формат входных данных
В первой строке записано натуральное число n. Далее в n строках записано по два целых числа: стоимость выполнения работы и затраты. Все числа не превосходят 1000.

Формат результата
Одно число — ответ к задаче.

Примеры
Входные данные
4
12 10
7 11
15 8
10 10
Результат работы
9
```
n = int(input())
total = 0

for _ in range(n):
    income, cost = map(int, input().split())
    profit = income - cost
    if profit > 0:
        total += profit

print(total)
```
