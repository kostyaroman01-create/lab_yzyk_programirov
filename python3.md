# задание 1
Первый класс
В школу пришло n первокласников. Из них надо сформировать несколько классов. При этом требуется соблюсти следующие условия: в классе не может учиться более 25 человек, количество классов должно быть наименьшим, количество учеников в каждом классе должно быть примерно одинаковым, то есть количество учеников в двух разных классов может различаться не более чем на 1. Ваша программа должна вывести два числа: количество классов и количество учеников в самом маленьком классе.
Формат входных данных
Одно натуральное число n, n≤1000
Формат результата
Через пробел два целых числа — количество классов и количество учеников в самом маленьком классе.
```
Примеры
Входные данные
69
Результат работы
3 23
Входные данные
101
Результат работы
5 20
```
```
import math

a=int(input())
k = math.ceil(a/25)
s= math.floor(a/k)
print(k, s)
```
* math.ceil(a/25) почему вверх потому что у нас остается дробная часть и в 2 класса она невлезит
* math.floor(a/k) потомучто нам требуется минимальное количество учеников в классе

# задание 2
Двоичная запись
Дано рациональное число вида p/q, где p и q — целые положительные числа. Напишите программу, которая переведет это число в двоичную дробь и найдет первые n разрядов этой дроби.

Программа должна дать ответ для t независимых наборов во входных данных.

Формат входных данных
В первой строке на вход подается одно число t — количество наборов входных данных, 1 ≤ t ≤ 100. Каждый набор входных данных состоит из двух строк. В первой строке записано одно натуральное число n — количество разрядов двоичной дроби, 1 ≤ n ≤ 1000. Во второй строке записаны два натуральных числа p и q — числитель и знаменатель рационального числа, 1 ≤ p < q ≤ 10000

Формат результата
Для каждого набора входных данных программа должна вывести двоичную дробь, у которой ровно n разрядов. Формат вывода смотрите по примерам.
```
Примеры
Входные данные
3
1
2 3
8
5 8
10
3 13
Результат работы
0.1
0.10100000
0.0011101100
```
```
a=int(input())
for i in range(a):
    n=int(input())
    p,q=map(int, input().split())
    s="0."
    for i in range(n):
        p*=2
        if(p>=q):
            p-=q
            s+="1"
        else:
            s+="0"

    print(s)

```
* Дробь p/q — это сколько частей из q. Умножение на 2 — сдвиг в двоичной записи. Если после удвоения числитель дотянул до знаменателя (или превысил), значит текущий разряд — единица, а лишнее уходит в остаток.
# задание 3
Сравнение
Даны четыре рациональных числа. (Рациональное число — это число вида p/q, где p и q — целые числа.) Напишите программу, которая сравнит сумму двух первых чисел с суммой двух последних чисел.

Ваша программа должна ответить на t независимых запросов во входных данных.

Формат входных данных
В первой строке записано одно натуральное число t — количество запросов, 1 ≤ t ≤ 10000. Каждый запрос записан в одной строке, которая содержит восемь целых чисел — числитель и знаменатель первого числа, второго, третьего и четвертого. Числители дробей являются целыми числами, не превосходящими 109 по модулю. Знаменатели являются целыми неотрицательными числами, не превосходящими 109.

Формат результата
Для каждого из запросов программа должна вывести число 0, если суммы равны; -1, если первая сумма меньше второй; 1, если если первая сумма больше второй. Все числа выводятся в одной строке через пробел.
```
Примеры
Входные данные
6
1 2 1 3 1 1 -1 12
1 6 2 5 -2 15 7 10
-1 2 -1 3 0 93 -5 6
2 1 3 1 4 1 1 1
-249194432 617244443 -26110763 224434363 -158608967 498895687 -56129511 277675007
62314249 499198669 446310315 499869641 16360901 310335913 775904647 804077933
Результат работы
-1 0 0 0 1 0
```
Примечания
В первом тесте ответ -1, так как 1/2+1/3 < 1/1+(-1/12).

Во втором тесте ответ 0, так как 1/6 + 2/5 = -2/15+ 7/10
```
n=int(input())
m=[]
for i in range(n):
    a1,b1,a2,b2,a3,b3,a4,b4=map(int, input().split())
    p1=a1*b2+a2*b1
    q1=b1*b2
    p2 = a3 * b4 + a4 * b3
    q2 = b3 * b4
    l=p1*q2
    r=p2*q1
    if(l==r):
        m.append(0)
    elif(l<=r):
        m.append(-1)
    else:
        m.append(1)

print(" ".join(map(str,m)))
```

# задание 4
Универсальный префиксный код
Универсальный префиксный код используется для представления последовательности произвольных натуральных чисел в алфавите {0,1}. Каждое число кодируется отдельно по следующему алгоритму. Пусть требуется закодировать число x. Запишем x в двоичной записи без ведущих нулей (x)2. Обозначим за y длину числа x в двоичной записи. Обозначим за z длину числа y в двоичной записи. Тогда код числа выглядит так: в начале записывается последовательность из z-1 нулей. далее число y в двоичной записи, далее число x в двоичной записи без старшего разряда. Например, закодируем число 83. (83)2=1010011, y=7, (y)2=111, z=3. Тогда, кодом числа 83 будет 00111010011.

При кодировании последвательности, каждое число кодируется отдельно, далее коды соединяются вместе без разделителей.

Ваша задача — закодировать заданную последовательность.

Формат входных данных
В первой строке записано одно натуральное число n — количество чисел для кодирования, n ≤ 100 Далее в строке через пробел записаны n натуральных чисел. Числа не превосходят 1018

Формат результата
Вывести требуемый код.
```
Примеры
Входные данные
5
83 1 2 8 83
Результат работы
00111010011101000010000000111010011
```

```
def dvoich(n):
    m = ""
    while n > 0:
        t = n % 2
        m = str(t) + m
        n = n // 2
    if m != "":
        return m
    else:
        return "0"

n = int(input())
ns = map(int, input().split())
r = []
for i in ns:
    x = dvoich(i)
    y = len(x)
    y1 = dvoich(y)
    z = len(y1)
    c = "0" * (z - 1) + y1 + x[1:]
    r+=c

print("".join(r))
```
